## Corrective history

Two bounded failed attempts were retained in CSC scratch for diagnosis:

1. job `184671` exited before module initialization because strict shell flags were enabled while
   sourcing CSC's non-interactive profile;
2. job `184707` initialized the GH200 and PyTorch module but its `srun` step did not inherit the
   module wrapper environment.

The final script uses a clean login shell, exports only CSC's non-interactive initialization switch
at submission, and sets `SLURM_EXPORT_ENV=ALL` only after the clean module environment exists.
