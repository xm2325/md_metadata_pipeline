A first implementation compared `(atom name, residue name, residue number)` over the entire system and reported 14,044 differences. Inspection showed that these were concentrated in glycan/non-protein residue-number representations. For example, the same `G2/BGLN/C1` atom occurred at the same atom index and segment but was labelled residue 1 in PSF and residue 9 in PDB.

The final gate therefore does not ignore the difference. It records exact and normalized all-atom comparisons as diagnostics, while compatibility is established by:

1. both PSF and PDB reading the same XTC;
2. identical atom and residue counts;
3. identical segment assignment, residue partition, and per-residue atom counts by atom index;
4. finite coordinates for all audited frames;
5. protein chemical identity after only documented CHARMM/PDB atom-name aliases.

This separates a file-format naming difference from a real topology or atom-order conflict.

## MD residue → PDB residue

The prepared Spike trimer contains protein chains A, B, and C. Each MD chain was aligned independently to every protein chain in PDBe's `6VXX` residue listing. Chain assignment used the best sequence score; because the three protomers are sequence-equivalent, all three assignments are formally tied. The same chain ID was then used as a transparent secondary rule:

```text
MD A → PDB A
MD B → PDB B
MD C → PDB C
```

This is recorded as `sequence_score_then_same_chain_id_tiebreak`, with `assignment_ambiguous=true` for all three chains.

## Acceptance gates

The run fails closed when any of the following occurs:

- a required public PSF, PDB, or XTC asset is absent;
- an asset exceeds its configured download limit;
- a partial download cannot complete;
- metadata, PSF, PDB, or trajectory atom counts disagree;
- PSF and PDB residue counts disagree;
- either topology cannot read the requested XTC frames;
- the trajectory contains non-finite coordinates;
- segment assignment, residue partition, or per-residue atom counts differ by atom index;
- protein atom identity falls below 99.9%;
- PDBe, UniProt, or PDB–UniProt validation does not pass;
- sequence identity falls below 95%;
- MD→PDB coverage falls below 95%;
- MD→PDB→UniProt coverage falls below 90%.
